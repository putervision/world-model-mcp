# Features — @putervision/world-model-mcp

## 1. PuterVision Autonomous Memory Triad
- **`@putervision/state-memory-mcp`**: Workflow state tracking, task DAGs, decision logging.
- **`@putervision/vision-memory-mcp`**: Visual caching, UI grounding, video ingestion.
- **`@putervision/world-model-mcp`**: 3D/2D spatial world model, entity permanence, movement simulation, and spatial SDD.

## 2. Interactive 3D WebGL Scene Visualizer
Run `world-model-mcp view` to launch a browser-based Three.js 3D viewport rendering entities, frustum cones, and spatial relation lines.

## 3. Cryptographic Spatial Evidence Packs
Generate tamper-evident SHA-256 evidence packages linking spatial action outcomes with state-memory task completion nodes.
