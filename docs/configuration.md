# Configuration Guide — @putervision/world-model-mcp

## Environment Variables
- `WORLD_MODEL_MCP_PROJECT`: Explicit project identifier to scope operations (default: current directory name).
- `WORLD_MODEL_STORAGE_DIR`: Custom directory path for SQLite databases (default: `.world-model-mcp/`).
- `LOG_LEVEL`: Logging verbosity (`debug`, `info`, `warn`, `error`).

## IDE Integration
Configuration snippets for `.cursor/mcp.json`, `.vscode/mcp.json`, and Gemini Antigravity are generated automatically by `world-model-mcp init`.
